# Elite Properties — Viewing and Enquiry Procedure

## Information to collect
For a viewing request, collect:
1. Customer name
2. Contact number
3. Property ID or property description
4. Preferred viewing date
5. Preferred viewing time
6. Any additional requirements

## Procedure
- Ask for missing information politely.
- Check that the requested property exists in the verified listings.
- Do not promise availability or confirm a viewing.
- Send the complete request for agent approval.
- Tell the customer that the agent must confirm the appointment.

## Escalation cases
Escalate negotiation, offers, legal questions, financing, ownership disputes, unavailable listings, and all unverified property details.
